==============================================================================
PART 6: MAXDD AND BOOTSTRAP (code-level review)
==============================================================================

MAXDD (from v601 code):
  - Equity curve is computed bar-by-bar.
  - Peak is running max of equity.
  - DD = (equity - peak) / peak * 100.
  - MaxDD = min(DD) over all bars.
  - Intra-bar DD is NOT captured (no high/low used in equity).

RECONSTRUCTED MaxDD from recorded trades (approximation):
  Since equity curve per bar is not stored, we cannot reconstruct
  intra-trade fluctuation. We CAN compute the running closed-trade
  equity curve from cumulative net_pnl.

  Dataset GAZP_2025_2026: closed-trade MaxDD = -99.6613%
  Dataset LKOH_2025_2026: closed-trade MaxDD = -99.7064%
  Dataset SBER_2024_2025: closed-trade MaxDD = -99.1153%
  Dataset SBER_2025_2026: closed-trade MaxDD = -97.0548%

  This is LOWER BOUND in absolute value than true bar-level MaxDD
  because it ignores intra-trade drawdown between entry and exit.

BOOTSTRAP (from v601 code):
  - Unit of resampling: session_key
  - Only sessions WITH at least one trade are included in sess_pnl
  - Sessions without trades are NOT in 'keys' and cannot be resampled
  - CI95 = [quantile(0.025), quantile(0.975)] of resampled expectancy means
  - It estimates the sampling distribution of expectancy under
    session-level resampling.

==============================================================================


1) CONFIRMED BY CALCULATION:
   - Cost decomposition (no_slip_no_comm / entry_slip / exit_slip / entry_comm / exit_comm / net)
     reconciliation residual is reported for each dataset.
   - Reason distribution per dataset.
   - holding_bars distribution per reason.
   - Data integrity (monotonic / duplicate / NaN / signal counts).
   - Signal difference between session-reset and full pct_change(6).

2) CONFIRMED BY CODE READING ONLY (not numerical):
   - H_MAX semantics: TP/SL checked on entry bar and following bars,
     time-stop on i where i - entry_index >= 12. Formally 13 bars of TP/SL window.
   - MaxDD formula and lack of intra-bar reconstruction.
   - Bootstrap excludes empty sessions from resampling.

3) NOT VERIFIED DUE TO MISSING DATA:
   - Exact per-bar equity curve from v601 (not stored).
   - Intra-bar drawdown (requires tick data).
   - Raw entry/exit prices before slippage (not stored per trade),
     but derivable from entry_price / exit_price given fixed slippage rate.
   - Minimum capital during run at each bar (only inferred from closed trades).

4) WHAT THIS MEANS FOR v601:
   - The cost decomposition from recorded trades reconciles to net_pnl
     within floating tolerance (see Part 1).
   - The signal used in v601 is consistent with the frozen v600 definition
     (differences reported in Part 4).
   - Structural uncertainty (H_MAX window size, empty-session bootstrap)
     is documented. It does not by itself invalidate the negative result.
