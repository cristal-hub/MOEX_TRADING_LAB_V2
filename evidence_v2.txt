  178: 
  179: ### 7.1. Calendar-session joint bootstrap
  180: 
  181: Session-block bootstrap with joint calendar-session resampling
  182: across all datasets present in period P.
  183: 
  184: For each replicate k = 1 .. N_iter:
  185: 
  186:   1. Form S_all = union of session_keys over all datasets in D_P.
  187:   2. Resample S_all with replacement -> S_k (size |S_all|).
  188:   3. For each dataset d in D_P:
  189:        - take sessions of d that appear in S_k,
  190:        - include all eligible bars from those sessions of d,
  191:        - preserve overlapping forward windows within each session,
  192:        - recompute О”_6^{d,k} by В§5.5.
  193:   4. Compute aggregate:
  194:        О”_6^{aggregate,k} = (1/|D_P|) В· ОЈ_d О”_6^{d,k}.
  195:   5. If for any d, any atr14 group g has N_event>0 and N_control=0
  196:      in the resampled data, mark the replicate INVALID for dataset d.

  199: 
  200:   - Sessions are shared across datasets: a calendar session is
  201:     present in all datasets for that day, or in none.
  202:   - Cross-instrument dependence is preserved because all three
  203:     datasets are resampled on the same calendar sessions.
  204:   - Forward windows are never joined across resampled sessions,
  205:     because each session is taken as a block from its own dataset.
  206:   - Aggregate uses equal weight per dataset.
